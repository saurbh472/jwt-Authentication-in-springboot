# Spring Boot Projects - From Basic Spring Security to JWT Authentication

This repository contains four Spring Boot projects, starting from basic Spring Security implementations to more advanced JWT authentication setups with database integrations. The projects support different Spring Boot versions, with one project updated to Spring Boot 3.4.1.

## Projects Overview:

1. **Basic Spring Security Setup**  
   - A simple implementation of Spring Security to protect endpoints and provide basic authentication.
   - **Spring Boot Version:** Older versions.

2. **Spring Security with Database Integration**  
   - An enhanced version where authentication and authorization are managed through a database (e.g., MySQL or MongoDB).
   - **Spring Boot Version:** Older versions.

3. **JWT Authentication Implementation**  
   - A project that demonstrates how to implement JWT-based authentication to protect your API endpoints.
   - **Spring Boot Version:** Older versions.

4. **JWT Authentication with Database Integration**  
   - A combination of JWT authentication and database integration for more robust user management and security.
   - **Spring Boot Version:** Up-to-date with Spring Boot 3.4.1.

## Key Features:

- **Spring Boot Compatibility:** Most projects are based on older versions of Spring Boot, while the final project is up-to-date with **Spring Boot 3.4.1**.
- **Security Implementations:** Covers both basic authentication and more advanced JWT-based solutions.
- **Database Integration:** Projects integrate with databases for managing user credentials and other necessary data.
